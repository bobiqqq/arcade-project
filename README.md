# Dungeon Runner

Небольшая 2D-игра на Python и Arcade в жанре top-down dungeon runner.

Игрок исследует уровни, собирает ключи и монеты, сражается с врагами и открывает выход на следующий уровень. Между уровнями можно улучшать здоровье, урон или скорость персонажа.

## Возможности

- 2 игровых уровня;
- два типа врагов: слизень и стрелок;
- стрельба мышью;
- сбор монет и ключей;
- ловушки-бомбы и столкновения с препятствиями;
- улучшение характеристик между уровнями;
- анимация персонажа и камера, следующая за игроком.

## Установка и запуск

Установите Python 3.10+ и библиотеку Arcade:

```bash
pip install arcade
```

Запустите игру из директории `app`:

```bash
cd app
python run.py
```

## Управление

- `WASD` или стрелки — перемещение;
- левая кнопка мыши — выстрел;
- `Space` — начать игру;
- `1`, `2`, `3` — выбрать улучшение между уровнями;
- `Enter` — продолжить;
- `Esc` — выйти.

## Структура проекта

- `app/` — исходный код игры;
- `app/levels/` — карты уровней Tiled;
- `app/assets/` — игровые ресурсы;
- `app/run.py` — точка запуска приложения.
